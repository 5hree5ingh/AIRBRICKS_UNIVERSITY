Drop your 3D model file here as:

    campus.glb

(.glb is the standard web 3D format — a single file, textures included.
 If your source is .gltf + separate texture files, export/convert to .glb
 instead: it's simpler to deploy and every 3D tool — SketchUp, Revit,
 3ds Max, Blender — can export straight to .glb, or convert free at
 https://products.aspose.app/3d/conversion/gltf-to-glb)

Once model/campus.glb exists, the "Step Inside An Airbrick Campus" section
on the website will load it automatically — no code changes needed.
